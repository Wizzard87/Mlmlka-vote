# Mlmlka wt frontend — GitHub Pages

Самостоятельный frontend HTML/CSS/JS. .NET и база данных на GitHub Pages не нужны.
Пошаговое подключение и выдача админки: `../SETUP-RU.md` в полном проекте.

- `index.html` — Discord-вход, выбор самолёта, один голос, обратный отсчёт, обновляемый рейтинг и победитель последнего завершённого голосования (сохраняется после перезагрузки страницы и открытия нового раунда).
- `admin.html` — длительность, фильтры каталога, «+ / −», открытие и закрытие голосования стримером.
- Пункт «Управление» скрыт у гостей и обычных пользователей; появляется после входа аккаунтом из `Auth__StreamerDiscordIds`.
- `config.js` — публичная настройка `apiBaseUrl`, например `https://api.example.com` (без `/api`).
- `app.js` — работа с API. Ключей бота/администратора и Discord ClientSecret во frontend нет.
- `voting-options.js` — значения BR от 14.7 до 1.0 и загрузка всех страниц каталога для голосования.
- `aircraft-images.js` — публичное соответствие ID изображений Wiki.
- `build_design.py` — необязательный генератор HTML-оболочек; для публикации не запускается.

## Публикация отдельно от бэкенда

1. Поместите **содержимое website**, включая `.github/workflows/pages.yml` и `.nojekyll`, в отдельный GitHub-репозиторий.
2. Укажите HTTPS-адрес API в `config.js`.
3. Settings → Pages → Source: GitHub Actions. Workflow публикует публичные файлы при push в `main`.
4. На VDS: `Frontend__Url=https://USER.github.io/REPO/index.html`, `Cors__AllowedOrigins__0=https://USER.github.io`.
5. Настройте Discord OAuth и ID стримера по `../backend/README.md`.

Относительные ссылки работают в подпапке GitHub Pages. Сессия в sessionStorage, запросы Bearer, сторонние cookies не нужны.
Сервер проверяет полномочия, время и уникальность голоса; таймер страницы только показывает оставшееся время.
Если ничего не выбрано вручную, в голосование попадают все самолёты по текущим фильтрам и поиску со всех страниц. Например, выберите «Реактивные» и откройте голосование; для всех самолётов сбросьте фильтры и оставьте ручной выбор пустым. При ручном выборе участвуют только отмеченные кнопкой «+» самолёты.
GitHub Pages не может обращаться к обычному `http://IP:порт`: API нужен действующий HTTPS (домен или сертификат для IP).
При недоступности API показывается ошибка, демонстрационные голоса не используются.
Изображения и шрифт загружаются из внешних CDN.

Локально: `python -m http.server 8765 --bind 127.0.0.1` из этой папки и отдельно backend на 5080.
GitHub Pages и VDS автоматически не публиковались.

Каталог голосований исключает серверный бан-лист: 291 самолёт скрыт, доступны 1033. Список и причины — `../backend/BANLIST.md` в полном проекте.
